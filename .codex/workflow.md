# workflow.md — 作業フロー

## 作業手順

タスクに取り組む際は以下の手順を守ってください：

1. **調査**: 影響範囲を把握してから変更に入る
2. **実装**: 既存コードのスタイル・命名規則・ファイル構成に合わせて実装する
3. **検証**: `npm run check` と `npm run build` を通す（テストは未導入。追加条件は AGENTS.md の「検証ハーネス」）
4. **報告**: 変更ファイルと実行結果を明示して報告する

シンプルな1行修正などは調査フェーズを省略して直接実装してよい。

## 開発サーバー

```bash
npm run dev
```

## ビルド

```bash
npm run build
```

## 品質チェック

```bash
npm run check
npm run lint
npm run lint:markup
npm run prettier:check
```

## 報告フォーマット

作業完了時は以下の形式で報告する：

### 変更ファイル

- `path/to/file`: （変更内容の要約）

### 実行結果

- ビルド: ✅ / ❌
- テスト: ✅ X件通過 / ❌ X件失敗（未導入ならその旨を明記）
- lint: ✅ / ❌（未導入ならその旨を明記）
